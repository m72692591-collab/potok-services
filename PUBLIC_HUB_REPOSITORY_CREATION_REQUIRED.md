# Публичный хаб ANIMA TACTUS не размещать внутри «Потока»

Эта временная ветка создана только как техническая страховка. Публичные образовательные материалы ANIMA TACTUS не должны размещаться в архивном репозитории `potok-services`, потому что это смешивает бренды, аналитику и поисковую историю.

Правильный следующий шаг — отдельный публичный репозиторий того же бренда либо подтверждённый публичный hosting. До этого `potok-services/main` остаётся `FROZEN / REDIRECT ONLY`.
