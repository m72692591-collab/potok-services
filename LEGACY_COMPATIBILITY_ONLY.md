# LEGACY_COMPATIBILITY_ONLY

Этот репозиторий не является отдельным активным проектом, брендом, продуктом или площадкой.

Его единственная функция:

```text
старый технический адрес
→ понятное уведомление
→ перенаправление на ПРАКСЕЛЬТУ / PRAXELTA
```

## Запрещено

- новая разработка продукта;
- новые услуги и тарифы;
- сбор заявок;
- реклама;
- аналитика поведения;
- отдельная база пользователей;
- возврат старого распространённого названия в активный бренд;
- смешивание с ANIMA TACTUS.

## Разрешено

- поддерживать безопасное перенаправление;
- объяснять, что адрес устарел;
- сохранять минимальную техническую совместимость;
- после проверки перенаправления архивировать репозиторий отдельным решением владельца.

Канонический активный проект: `m72692591-collab/praxelta-services`.
