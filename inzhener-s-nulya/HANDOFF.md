# Передача состояния

Текущий backend работает на `https://inzhener-s-nulya.vercel.app`; 2026-09-25 его readiness сообщил `launchReady=true`. Не менять Т-Бизнес, НПД, webhook, хранилище и выдачу при создании витрины.

Следующий исполнимый шаг после восстановления управляемого браузера: открыть `business.yandex.ru`, выбрать подтверждённую организацию, прочитать её текущие данные и заполнить сайт по `YANDEX_BUSINESS_CONTENT.md`. Не нажимать «Сохранить и опубликовать», пока не проверен бесплатный маршрут без видимого `*.vercel.app`.

Точный текущий блокер: Computer Use не получает ни одного браузера и возвращает `Unable to load browser request-header policy` даже после повторов, сброса сессии, включённого расширения ChatGPT в Chrome и повторной проверки после действия владельца «готово». `cua.listWindows()` в текущем рантайме недоступен, поэтому управлять открытым Chrome как обычным окном тоже нельзя. Локальных ключей Object Storage и CLI-профиля нет, поэтому независимое развёртывание промежуточного URL невозможно без доступа к уже созданному ключу или к кабинету.

Секреты в репозиторий не добавлять. Yandex AI Studio не открывать и не вызывать.

Локальная статическая сборка проверена командой `npm --prefix inzhener-s-nulya run build:yandex`; она создаёт `dist-yandex` и намеренно показывает закрытие продаж до переноса защищённой оплаты. Публиковать её как магазин нельзя.

2026-09-25 создан bucket `inzhener-s-nulya-1790344532628`, в него загружен `dist-yandex` и включён website hosting. Внешние URL пока дают 403, потому что сервисный аккаунт с `storage.editor` не смог поставить публичную bucket policy: `PutBucketPolicy` вернул `AccessDenied`. Следующий шаг: выдать этому сервисному аккаунту `storage.admin` на каталог или открыть публичный доступ к объектам вручную в консоли.
