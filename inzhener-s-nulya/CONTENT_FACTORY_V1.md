# Контент-завод «Инженер с нуля» — версия 1

## Задача

Производить короткий вертикальный контент без участия владельца и без обязательной съёмки человека.

Источники контента:
1. канонический курс AutoCAD и его учебный проект РВС-5000;
2. канонический курс Primavera P6;
3. бесплатные уроки и типовые ошибки новичков;
4. вопросы из автоматического помощника сайта;
5. фактические поисковые запросы и рекламные UTM после накопления данных.

## Откуда берётся видеоряд

Никаких случайных чужих роликов.

Типы кадров:
- анимированные инженерные схемы;
- стилизованные CAD-подобные макеты без копирования интерфейса AutoCAD;
- таймлайны и WBS-схемы для Primavera;
- фрагменты собственных учебных PDF/DXF/таблиц, когда права и формат позволяют;
- титры, стрелки, размеры, координаты, слои, графики;
- позже — реальные screen capture-фрагменты из учебной среды, когда появится облачная/авторизованная среда рендера.

На этапе привлечения зрителю важнее понять одну операцию за 20 секунд, чем смотреть говорящую голову.

## Производственный цикл

1. Очередь тем: `content/video_queue_v1.json`.
2. Из hook + brief автоматически создаётся сценарий 18–28 секунд.
3. Генерируются 5–7 кадров/сцен.
4. Добавляется русская синтетическая озвучка и крупные субтитры.
5. Финальный CTA только один: бесплатный набор.
6. Выходы: 9:16 master + обложка + подпись + UTM/source code.
7. Публикация: VK Клипы, YouTube Shorts, затем другие разрешённые площадки.
8. Аналитика: источник сохраняется как `eng_<source>` в Telegram deep link и `src=<source>` на сайте.
9. Темы с плохим переходом отключаются; победители получают 3–5 новых вариаций.

## Ограничения качества

- не показывать выдуманный интерфейс как настоящий AutoCAD/Primavera;
- не использовать чужие ролики, логотипы и платные шаблоны без прав;
- не обещать трудоустройство или доход;
- не давать непроверенные нормативные/промышленно-безопасные советы;
- технический ролик должен учить одной проверяемой операции;
- сложные вопросы ведут в курс или автоматический помощник, а не маскируются упрощённым ответом.

## Рендер

Основной внешний видео-рендерер можно подключить позже. На текущем аккаунте Motion.so не имеет кредитов, поэтому денежные покупки не выполнялись. До появления бесплатного/оплаченного рендера очередь и сценарии остаются renderer-agnostic.

Варианты без участия владельца:
- облачный video-render API;
- motion-graphics renderer;
- шаблонный HTML/SVG → видео pipeline в облачном Runtime;
- подключаемый редактор с API.

## Консультации без владельца

Уровень 1 — уже подготовлен: `/support` + `/api/engineer-support`, детерминированная база типовых вопросов работает без модели.

Уровень 2 — существующий `@AnimaTactusPartner_bot`: команды Engineer в одном Telegram Runtime.

Уровень 3 — AI FAQ/RAG: подключается облачная модель к утверждённой базе курсов. Модель должна отвечать только из базы и явно не выдумывать шаги, если материал не найден.

Владелец не участвует в обычных консультациях. Человеческая эскалация нужна только для спорного платежа, юридического требования или ошибки, которую нельзя безопасно решить автоматически.
