# Развёртывание на Replit Starter

## Подготовленная конфигурация

Replit импортирует корень `potok-services`. Файл `/.replit` содержит:

- build: `npm ci --prefix inzhener-s-nulya --omit=dev`;
- run: `npm --prefix inzhener-s-nulya start`;
- порт приложения: 3000, внешний HTTP: 80.

Само приложение также запускается из папки командой `npm start`. Отдельной сборки HTML не требуется.

## Replit Secrets

Значения добавляются только через Secrets. Обязательные production‑переменные:

| Имя | Назначение |
|---|---|
| `APP_PUBLIC_URL` | точный `https://…replit.app` без завершающего `/` |
| `PAYMENT_PROVIDER` | `tbank` |
| `TBANK_ENV` | `production` |
| `TBANK_TERMINAL_KEY` | терминал Т‑Бизнеса |
| `TBANK_PASSWORD` | пароль API Т‑Бизнеса |
| `ORDER_HMAC_SECRET` | случайная строка не короче 32 символов |
| `BLOB_READ_WRITE_TOKEN` | доступ к существующему приватному Blob |
| `NPD_ADMIN_TOKEN` | доступ к административному НПД‑интерфейсу |

В фактическом Vercel‑проекте отдельного `NPD_ADMIN_TOKEN` нет: административную проверку обеспечивает `CONTROL_PURCHASE_TOKEN` как предусмотренный кодом fallback. Также обнаружены резервные `YANDEX_PAY_API_KEY`, `YANDEX_PAY_MERCHANT_ID` и `YANDEX_PAY_ENV=sandbox`.

`CONTROL_PURCHASE_ENABLED=false`. `CONTROL_PURCHASE_TOKEN` не нужен, пока контрольная покупка выключена. Реквизиты продавца имеют действующие значения по умолчанию, но при переносе могут быть заданы соответствующими `BUSINESS_*` переменными.

Секреты Vercel OIDC не переносятся: Replit не получает `VERCEL_OIDC_TOKEN`. Для внешнего runtime нужен обычный `BLOB_READ_WRITE_TOKEN` существующего store.

Vercel‑переменные типа `Sensitive` необратимо скрыты после сохранения. Подтверждённый список: `CONTROL_PURCHASE_TOKEN`, `TBANK_PASSWORD`, `TBANK_TERMINAL_KEY`, `BLOB_READ_WRITE_TOKEN`, `YANDEX_PAY_API_KEY`, `YANDEX_PAY_MERCHANT_ID`, `ORDER_HMAC_SECRET`. Их нужно вводить в Replit Secrets из исходных значений; API Vercel не является источником plaintext. Не заменять `ORDER_HMAC_SECRET` случайным значением: он нужен для совместимости существующих токенов заказов и зашифрованной НПД‑сессии.

## Публикация

1. Перенести пять существующих production‑значений из Vercel в Replit Secrets без изменения Vercel deployment.
2. Проверить, что `APP_PUBLIC_URL` равен зарезервированному Replit‑адресу.
3. Выполнить публикацию Starter без billing.
4. Проверить, что Replit‑маршрут и его API не перенаправляют покупателя на `vercel.app`.
5. Проверить `GET /api/readiness`: payment production, order secret, Blob и NPD готовы; `launchReady=true`.
6. Проверить главную и все юридические страницы на desktop и viewport 390×844.

Существующий Vercel deployment не отключать, не снимать с публикации и не менять его домены. Он остаётся отдельным вторым сайтом. В рекламных материалах владелец планирует обозначать его как адрес, требующий VPN; реклама здесь не запускается.

## Проверка оплаты без списания

Для каждого SKU `autocad`, `primavera`, `bundle`:

1. ввести тестовый контакт владельца, принять оферту и нажать кнопку покупки;
2. проверить, что backend вернул URL домена `pay.tbank.ru`;
3. на форме банка сверить сумму 1 990/2 490/3 490 ₽;
4. не вводить карту и не подтверждать платёж;
5. проверить по созданному заказу, что `NotificationURL=/api/tbank-webhook`, а success/fail возвращают на Replit `order.html`.

Страница `result=success` не доказывает оплату. Выдача открывается только после `GetState=CONFIRMED` с полным совпадением заказа.

## Проверка выдачи

Текущий код выдаёт приватный объект Vercel Blob через подписанный URL сроком две минуты, с окном выдачи 24 часа и лимитом три скачивания. Проверять на ранее подтверждённом заказе. Если в аккаунте будет найден отдельный Google Drive‑контур, сначала зафиксировать его файл/папку и способ закрытого доступа, затем добавить адаптер и тест; публичные Drive‑ссылки для платных архивов запрещены.

## Откат

Если Replit не проходит readiness, переводит покупателя на `*.vercel.app`, формирует неверную сумму/URL или не подтверждает закрытую выдачу, не направлять на него покупателей. Остановить новую публикацию, сохранить журнал и оставить действующий Vercel deployment без изменений. Никаких реальных платежей и рекламы во время проверки.
