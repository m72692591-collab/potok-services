# Развёртывание витрины Яндекс Бизнеса

## Предварительные проверки

1. Выбрать подтверждённую организацию владельца «Инженер с нуля» в Яндекс Бизнесе.
2. Проверить роль владельца или представителя и бесплатный статус сайта.
3. Не включать рекламную подписку, приоритетное размещение, платёжные продукты Яндекса или AI Studio.
4. Сверить цены и названия с `MASTER_CONTEXT.md`.
5. Убедиться, что промежуточный URL не показывает `*.vercel.app` и сохраняет согласие с офертой, контакт, заказ, возврат после оплаты и защищённую выдачу.

Локальная подготовительная сборка: `npm --prefix inzhener-s-nulya run build:yandex`. Она создаёт `dist-yandex` для Object Storage и закрывает продажи до появления проверенного серверного маршрута. Это не полноценная публикация магазина.

Деплой-скрипт читает ключи из переменных окружения или из локального файла `inzhener-s-nulya/.env.local`. Файл `.env.local` исключён из Git; пример без секретов лежит в `.env.example`.

Для создания bucket и загрузки объектов достаточно роли `storage.editor`. Для управления bucket policy нужен расширенный доступ: после добавления `storage.admin` `PutBucketPolicy` прошёл. Отдельные публичные флаги/ACL bucket через текущий S3-ключ не изменились: `PutBucketAcl` и `PutObjectAcl` вернули `AccessDenied`; публичное чтение объектов нужно включить в консоли Yandex Cloud.

## Внесение данных

Использовать `YANDEX_BUSINESS_CONTENT.md` как карту полей. Юридические документы должны открываться полностью; выдержки вместо документов не допускаются.

## Аналитика

Встроенный счётчик сайта Яндекс Бизнеса считать только статистикой витрины. Сквозные цели настраивать на управляемом промежуточном URL и backend после появления бесплатного проверенного маршрута. Обязательные события:

- `view_course` с идентификатором товара;
- `begin_checkout`;
- `payment_redirect`;
- `purchase_confirmed` только после авторитетного статуса Т-Бизнеса.

## Проверка после публикации

1. Зафиксировать адрес `*.clients.site` и статус публикации.
2. Проверить главную на компьютере и мобильном устройстве.
3. Открыть каждую карточку и сверить название, срок и цену.
4. Открыть каждую юридическую страницу и сверить полный текст.
5. Начать оформление каждого товара без реальной оплаты; проверить контакт, согласие и переход на защищённую форму Т-Бизнеса.
6. Реальную оплату выполнять только по отдельному финансовому согласию.
7. Сохранить URL/ID и read-after-write доказательство.

## Откат

Если переход к оплате показывает `*.vercel.app`, теряет товар/контакт/согласие либо юридические документы недоступны полностью, снять сайт с публикации и сохранить текущую торговлю без изменений.
