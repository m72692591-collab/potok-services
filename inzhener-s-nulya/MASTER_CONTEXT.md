# Инженер с нуля — единый контекст

## Цель

Перенести существующий магазин из папки `inzhener-s-nulya` на публичный Replit Starter App. Покупатель Replit проходит главную, юридические страницы, оформление заказа, возврат из Т‑Бизнеса и получение курса без переходов на `*.vercel.app`.

Существующий Vercel deployment остаётся вторым действующим сайтом. Его не отключают и не изменяют при переносе. В будущих рекламных материалах владелец планирует указывать оба адреса, причём Vercel — с пометкой о необходимости VPN. Запуск и изменение рекламных кампаний в эту задачу не входят.

## Канонические товары

1. AutoCAD для стройки и исполнительной документации — 21 день, версия 2.0 — 1 990 ₽.
2. Primavera P6 с нуля для строительства — 14 дней — 2 490 ₽.
3. Инженер с нуля: AutoCAD + Primavera P6 — 3 490 ₽.

Цены и состав нельзя менять без прямого решения владельца.

## Сохраняемый торговый контур

- Эквайринг: Т‑Бизнес, production.
- Налоговый режим: ИП на НПД; чек создаётся существующей автоматизацией «Мой налог» после авторитетного статуса `CONFIRMED`.
- Юридические страницы: `/offer`, `/privacy`, `/payment`, `/delivery`, `/return`, `/contacts`, `/requisites`.
- Заказ связывает `OrderId → PaymentId → product → amount`; доступ выдаётся только после `GetState` с точным совпадением `TerminalKey`, `OrderId`, `PaymentId`, суммы и статуса.
- Секреты разрешены только в Replit Secrets/переменных окружения. В Git и документацию значения не записываются.
- Бюджет 0 ₽. Billing, покупка домена, платный тариф и реклама не включаются.

## Фактическое хранилище

В текущем репозитории и его истории выдача реализована через приватный Vercel Blob и краткоживущую подписанную ссылку. Кода или конфигурации Google Drive в проекте нет. Требование «сохранить Google Drive» пока не подтверждено исходниками; нельзя объявлять его выполненным до обнаружения реального Drive‑контура или его идентификаторов в аккаунте. Replit‑адаптация сохраняет существующий приватный Blob, не публикует архивы и не переносит секреты в код.

## Replit

- Репозиторий импортируется целиком; корневой `.replit` запускает `inzhener-s-nulya`.
- Build: `npm ci --prefix inzhener-s-nulya --omit=dev`.
- Start: `npm --prefix inzhener-s-nulya start`.
- Сервер слушает `0.0.0.0:$PORT`, обслуживает статические страницы и существующие API‑обработчики.
- После выдачи адреса `*.replit.app` он записывается в `APP_PUBLIC_URL`; этот адрес формирует `NotificationURL`, `SuccessURL` и `FailURL` Т‑Бизнеса.

## Критерий готовности

Статус `ГОТОВО` допустим только после всех пунктов:

1. Replit App создан в текущем аккаунте из данного GitHub‑репозитория; Vercel deployment сохранён без изменений.
2. Все production‑секреты заданы в Replit Secrets, публикация Starter выполнена без billing.
3. Публичный URL отвечает, не перенаправляет покупателя на `*.vercel.app`, а `/api/readiness` возвращает `launchReady=true`.
4. Главная и все семь юридических страниц проверены на desktop и mobile.
5. Для трёх товаров проверено начало заказа без реального платежа: сумма, товар, домен `pay.tbank.ru`, success/fail URL и webhook ведут на Replit.
6. Выдача проверена на ранее подтверждённом или специально разрешённом контрольном заказе без нового финансового списания.
7. Для публикации сохранены URL и read-after-write доказательство.
