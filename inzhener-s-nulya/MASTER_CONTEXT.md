# Инженер с нуля — единый контекст

## Цель

Запустить публичную витрину для пользователей из России на бесплатном сайте Яндекс Бизнеса, сохранив существующую автоматическую торговлю через Т-Бизнес и текущий backend.

## Канонические товары

1. AutoCAD для стройки и исполнительной документации — 21 день, версия 2.0 — 1 990 ₽.
2. Primavera P6 с нуля для строительства — 14 дней — 2 490 ₽.
3. Инженер с нуля: AutoCAD + Primavera P6 — 3 490 ₽.

Цены и состав нельзя менять без прямого решения владельца.

## Торговый контур

- Основной эквайринг: Т-Бизнес.
- Налоговый режим: ИП на НПД.
- Чек НПД формируется существующей автоматизацией через «Мой налог».
- Чеки Т-Бизнеса по 54-ФЗ не подключаются.
- Robokassa не используется.
- Защищённая выдача курса остаётся в существующем backend.
- Yandex AI Studio, Playground и API моделей не используются до решения по Boost.
- Бюджет: 0 ₽; реклама и платные функции не запускаются.

## Обязательная публичная информация

На витрине должны быть доступны без сокращений: публичная оферта, политика обработки персональных данных, оплата, получение цифрового товара, возврат, контакты и реквизиты.

SEO title: «Инженер с нуля — AutoCAD и Primavera P6 для строительства».

SEO description: «Пошаговые курсы самообучения AutoCAD и Primavera P6 для начинающих инженеров и специалистов строительной отрасли. Практика на учебном проекте.»

## Критерий готовности

Витрина считается запущенной только после публикации на `*.clients.site`, проверки мобильного вида, карточек и юридических материалов, а также сквозной проверки начала заказа через Т-Бизнес без показа покупателю адреса `*.vercel.app`. Для внешних изменений сохраняются URL/ID и результат чтения после записи.
