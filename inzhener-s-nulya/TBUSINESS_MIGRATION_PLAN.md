# Перенос публичного сайта «Инженер с нуля» в Т‑Бизнес

Статус: **ОБЯЗАТЕЛЬНЫЙ БЛОКЕР ПЕРЕД РЕКЛАМОЙ И МАССОВЫМИ ПРОДАЖАМИ**

Причина: текущий публичный адрес `inzhener-s-nulya.vercel.app` недоступен пользователю из РФ без VPN. Российский покупатель не должен устанавливать VPN или разбираться с обходами.

## Целевая схема

1. **Публичный сайт и витрина** — Конструктор сайтов Т‑Бизнеса.
   - Основная страница «Инженер с нуля».
   - Карточки AutoCAD, Primavera P6 и комплекта.
   - Оферта, политика ПД, оплата, получение, возвраты, контакты и реквизиты.
   - Мобильная версия.
   - Собственный адрес на Т‑Бизнесе; затем подключить собственный .ru-домен.

2. **Оплата** — интернет‑эквайринг Т‑Бизнеса.
   - Карты.
   - T‑Pay.
   - СБП и другие доступные методы.
   - Сохранить текущие цены: AutoCAD 1 990 ₽, Primavera 2 490 ₽, комплект 3 490 ₽.

3. **НПД и чеки** — текущая автоматизация «Мой налог».
   - После подтверждённого платежа автоматически формировать чек НПД.
   - Не требовать от владельца ручного создания чека.
   - При полном возврате автоматически отменять соответствующий чек НПД.

4. **Выдача цифрового товара**.
   - Не отправлять покупателя на `*.vercel.app`.
   - Перенести пользовательскую страницу заказа/скачивания на доступный из РФ адрес.
   - Сохранить ограничение скачивания и журнал выдачи.
   - Чек ФНС показывать покупателю на доступной из РФ странице и/или отправлять на его контакт.

5. **Backend**.
   - Vercel можно временно оставить только для server-to-server задач, если Т‑Банк и ФНС стабильно обращаются к нему.
   - Все URL, которые открывает покупатель, должны быть доступны из РФ без VPN.
   - Перед рекламой проверить минимум с мобильного интернета и домашнего провайдера РФ без VPN.

## Порядок работ

1. Создать сайт в Т‑Бизнесе: «Все сервисы» → «Привлечение клиентов» → «Конструктор сайтов» → «Создать сайт».
2. Перенести дизайн, тексты и юридические страницы с текущего «Инженер с нуля».
3. Создать три товара и подключить действующий интернет‑эквайринг.
4. Настроить обязательные поля покупателя: email/телефон, согласие с офертой и политикой ПД.
5. Настроить страницу успешной оплаты.
6. Перенести пользовательскую выдачу курса с Vercel на адрес, доступный из РФ.
7. Связать оплату Т‑Бизнеса → webhook → автоматический чек НПД → выдача курса.
8. Провести контрольную покупку.
9. Проверить сайт **без VPN из РФ**.
10. Только после успешной проверки открыть рекламу и массовый трафик.

## Критерий готовности

Реклама не запускается, пока одновременно не выполнено:
- сайт открывается из РФ без VPN;
- платеж проходит;
- чек НПД создаётся автоматически;
- покупатель получает чек;
- покупатель получает курс;
- ни одна покупательская ссылка не ведёт на недоступный из РФ `*.vercel.app`.
